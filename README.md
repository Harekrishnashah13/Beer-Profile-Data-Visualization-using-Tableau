# 🍺 Beer Profile Analytics Dashboard  
**Interactive Tableau Visualization | Data Exploration & Consumer Insights**  
_By Harekrishna Shah_

---

## 📘 Project Overview

This project is a data visualization and analysis exercise built in **Tableau** to explore various characteristics of different beer styles. It offers a deep dive into the **flavor profiles, alcohol content, bitterness (IBU), and regional trends** of beers across categories.

The goal is to provide **data-driven insights** for enthusiasts, brewers, and marketers through a **visually intuitive dashboard**.

---

## 🧠 Objectives

- Analyze and visualize a variety of **beer styles** and their key attributes.
- Identify trends across **Alcohol by Volume (ABV)**, **International Bitterness Units (IBU)**, and **Flavor**.
- Enable users to **filter and explore beer data** using interactive Tableau elements.
- Support **data-driven decision making** in the food & beverage industry.

---

## 📂 Dataset: `BeerProfiles.csv`

The dataset includes the following features:
| Column         | Description                                  |
|----------------|----------------------------------------------|
| Beer_Name      | Name of the beer                             |
| Style          | Type or category of beer                     |
| ABV (%)        | Alcohol by Volume                            |
| IBU            | Bitterness rating (International Bitterness Units) |
| Aroma/Flavor   | Notes on taste, hops, malt profile           |
| Location       | Origin region or brewery location            |

---

## 📊 Dashboard Highlights

- 📈 **ABV vs. IBU Plot**: Visualizes the relationship between alcohol strength and bitterness.
- 🌍 **Geographic View**: Highlights regional beer trends and strengths.
- 📊 **Bar Charts**: Top styles by average ABV or IBU.
- 🧪 **Flavor Analysis**: Explore popular flavor categories and aroma notes.
- 🧩 **Interactive Filters**: By region, style, bitterness range, and alcohol content.

## 📌 Key Insights

- Certain beer styles like **IPAs and Imperial Stouts** dominate in both alcohol and bitterness.
- **European and American beers** differ significantly in ABV and IBU trends.
- **Balanced ABV–IBU profiles** appear in lager, amber, and wheat beer categories.
- Geographic segmentation helps understand regional consumer preference.
